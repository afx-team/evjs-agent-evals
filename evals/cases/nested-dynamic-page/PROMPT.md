# 补齐团队详情

当前应用有首页和 `/teams` 团队列表，团队数据保存在 `src/pages/teams/data.ts`。请增加 `/teams/:teamId` 详情页，使用现有数据展示当前团队的名称与成员数。

在团队列表中，把团队名称变成 SPA 站内链接。打开详情时，`Teams` 标题及完整团队导航仍然可见；详情用一个二级标题显示团队名称，并显示 `Members: 3` 这样的成员数文案。切换团队、直接打开详情、刷新和浏览器前进后退都要显示正确数据。

未知团队 ID 应显示 `Team not found`，此时仍保留 `Teams` 标题、两个团队链接和全局 `Home` 链接。不要把团队 ID 硬编码成两条独立页面，使用 evjs 的动态目录与嵌套路由机制。保留原首页标题 `EVJS eval` 和现有全局导航，首页仍能通过站内链接打开 `/teams`。
