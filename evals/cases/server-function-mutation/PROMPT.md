`/notes` 页面通过 evjs Server Functions 管理便签。目前点击保存后列表不刷新；刷新页面后，新便签的标题和内容又颠倒了。请修复参数传递和查询缓存更新。

验收行为：

- 页面保留“便签”标题、“标题”和“内容”两个带可访问名称的输入框，以及“保存”按钮。
- 初始便签“欢迎 / 第一条便签”仍存在。
- 输入不同的标题、内容后保存，服务器按现有约定去掉前后空白并存下正确的字段，页面在不整页刷新的情况下显示新增项；成功后清空两个输入框。
- 连续保存两条不同便签都成功；浏览器刷新后两条仍存在，进程内保存即可，不要求数据库。
- 标题或内容只含空白时不能创建便签，页面用 `role="alert"` 展示服务端错误“标题和内容不能为空”。合法输入保存后不再显示这个旧错误。
- 保持现有 `createNote(title: string, body: string)` 两个必填位置参数的服务端接口和 `getNotes()` 查询接口。使用当前 evjs 的 Server Function 调用与缓存辅助 API，不手写 RPC URL、函数 ID、REST 替代接口或 localStorage 数据库。

不要修改依赖；保留首页 `EVJS eval`。
